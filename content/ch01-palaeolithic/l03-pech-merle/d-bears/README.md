# Beat d · the Bear's Gallery

No tour comes down here. The concrete stops at the Chapel and does not start again until
the last chamber, and for the whole of this gallery the only thing telling the tourist
where the floor is is a line of prints and a lamp that reaches about a body's length.

Seven hollows in the clay, alternating narrow and wide. The prints thread between them and
stop dead at each one, which is the only warning there is and is a completely reliable one.

Cave bears wintered in galleries like this and scraped themselves hollows to do it in;
the nests survive in the clay of a good many French caves. **The game opens them into the
gallery below**, which is a lie and is written up as one in LEVEL.md: a real bear nest is
thirty centimetres deep and would cost a visitor nothing but their dignity.

No new art. The hollows are drawn by the game as holes in `tile-clay` with a lit rim.
