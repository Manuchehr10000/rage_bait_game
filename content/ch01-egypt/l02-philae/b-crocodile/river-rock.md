# A river rock

| | |
|---|---|
| Id | `river-rock` |
| File | `river-rock.png` (not painted yet: the game draws its own until this file exists) |

| Beat | `b-crocodile` |

## What it is

A dark rock just breaking the surface of the river. 24 × 8, the waterline at the bottom edge.

## Where it stands in the game

Beat b, two of them: the second is a rock and the first is not. Also drawn for the crocodile before it moves, so this sprite must be identical to the crocodile at rest.

## Must be right

It has to be a convincing rock, and it has to be exactly what a crocodile's back could be mistaken for: the same width, the same bumps.

## Deliberately wrong

None. Everything about this one is meant to be right.

## Easter eggs

None.

## Sources

Photographs of the cataract rocks and of a crocodile's back at the surface.

## Confidence

Design choice.
